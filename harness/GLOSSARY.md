# GLOSSARY.md — 공유 용어집

> 에이전트와 사람이 같은 단어를 같은 뜻으로 쓰게 한다. 세션 간 용어 표류를 막는 장치.

## 표기 충돌 주의 (ADR-0008)
"계층"이 두 가지를 가리켰다. 아래 표기로 분리한다.

| 대상 | 표기 | 이전 표기 |
|---|---|---|
| 비용 계층 | 계층 A / B / C | (동일) |
| 로딩 단계 | **메타 / 본문 / 번들** | 계층 1 / 2 / 3 |
| 사다리 단계 | L1~L4 | (동일) |

백서에 남은 "계층 2"는 "본문", "계층 3"은 "번들"로 읽는다.

## 팩 공통 용어
| 용어 | 정의 |
|---|---|
| DoR (Definition of Ready) | phase 진입조건. 만족해야 작업 시작 가능 |
| DoD (Definition of Done) | phase 완료 게이트. 전부 충족해야 완료 |
| 불변식 (Invariant) | 절대 위반 불가 규칙. 1건 위반 시 통과 금지(`INVARIANTS.md`) |
| 게이트 (Gate) | 측정 가능한 통과/실패 판정 기준 |
| 증거 (Evidence) | 게이트 통과의 근거가 되는 명령과 출력 |

## TEA 고유 용어
| 용어 | 정의 |
|---|---|
| 계층 A | 일회성 절감. 산출물 자체의 크기. TEA의 비목표 |
| 계층 B | 복리 절감. 쓰지 않은 코드가 이후 모든 턴에서 과금되지 않음. Ponytail 담당 |
| 계층 C | 계수 절감. 턴 수 자체를 줄임. **TEA의 정의역** |
| 규율 축 | READ / WRITE / THINK 3개. SAY는 ADR-0003으로 제거 |
| 사다리 | 행동 전 통과하는 순차 판단 4단계(L1~L4) |
| 측정 핸들 | 규칙 준수 여부를 세션 로그에서 판정하는 관측 항목. 규칙 12개에 1:1 대응 |
| 불가침 | 어떤 최적화도 축소하지 않는 5항목 — 신뢰 경계 검증·예외 처리·데이터 손실 방지·보안·접근성 |
| hop | 간접 참조 1단계. 에이전트에게 고정 읽기 비용 발생 |
| 순기여 | C군 − B군. TEA 단독 효과. A군은 참조용(INV-9) |
| 채택 게이트 | 5조건 AND 판정. 총 토큰 단독으로는 채택 불가(INV-7) |
| 언더트리거 | 스킬이 필요한 상황에서 발화하지 않는 현상. 문구 문제이며 패키징 문제가 아님 |
| 목적 함수 동형성 | 토큰을 목적으로 삼는 것 자체가 측정 밖 축으로 비용을 전가할 위험(ADR-0005) |
| 반증 | 채택 게이트 미통과. phase 실패가 아니라 결과(`HARNESS.md` §2.3) |
| 티컵 예산 | 소비 상한 + 리필 확인. v1 제외(ADR-0001) |

## 외부 도구
| 이름 | 관계 |
|---|---|
| Ponytail | 계층 B 담당. 선택적 선행 의존. B·C군 공통 조건 |
| caveman | 출력 표현 담당. 정의역 위임(ADR-0003). 총 토큰 반례의 출처 |
