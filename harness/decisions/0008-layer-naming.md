# ADR-0008: "계층" 표기 충돌 해소 — 로딩 단계는 메타/본문/번들

- 상태: 채택 | 기록: 2026-08-13 (하네스 인스턴스화 시점 결정의 재구성 기록)

## 컨텍스트
"계층"이 두 가지를 동시에 가리켰다 — 비용 계층 A/B/C(TECHNICAL §3.1)와 스킬 로딩 단계 1/2/3(TECHNICAL §5.1). 세션 간 용어 표류 위험.

## 결정
비용은 계층 A/B/C를 유지한다. 로딩 단계는 **메타**(name+description, 상시) / **본문**(SKILL.md, 트리거 시) / **번들**(references/, 필요 시)로 개칭한다.

## 결과
백서 원문에 남은 "계층 1/2/3"은 메타/본문/번들로 읽는다(GLOSSARY 병기). 신규 문서는 새 표기만 쓴다. INV-3의 대상은 "본문"이다.
