# ADR-0010: 트리거 전략 개정 — description 단독에서 CLAUDE.md 로딩 어댑터 병용으로

- 상태: 채택 | 기록: 2026-08-18 (M1 반증에 따른 개정 — 사용자 결정 C-1)

## 컨텍스트
M1 실측(문안 3종 × 픽스처 2규모, 감사 통과 계측, 전량 유효 관측)에서 유기적 코딩 문항의
description 단독 발화율이 ≈47%(24/51)로 수렴했다. 검증 게이트(15트라이얼 중 13) 통과 확률 ≈0.4%.
키워드 언급 문항만 6/6. 문구를 공격적으로 밀면 골프 오발화(DoD 4 훼손)가 시작되는
정밀도-재현율 충돌도 확인됐다. TECHNICAL §5.3.1("언더트리거는 문구 문제")이
Claude Code CLI 2.1.233 + sonnet-5 headless에서 **반증**됐다. §5.3.2는 결정적 주입을 이미 예고했다.

## 결정
배포물에 **로딩 어댑터 지시문**(프로젝트 CLAUDE.md 2문장)을 포함한다. M1 게이트 수치는 불변,
측정 조건에 "어댑터 포함"을 명시한다(프로토콜 v2.2). description은 v1(§3.2 초안)로 복원한다 —
recall 부담이 어댑터로 이관되므로 정밀도가 검증된 보수 문안을 유지한다.

## 근거
- ADR-0002 정합 — 행동=스킬, 로딩=어댑터. CLAUDE.md 지시문은 플러그인 전환(M7) 전의 최소 어댑터다
- 게이트 수치·조건은 그대로다. 바뀌는 것은 측정 대상 시스템의 정의(스킬 단독 → 스킬+어댑터)뿐

## 결과
- 픽스처 중립성 규칙에 어댑터 파일(CLAUDE.md) 예외 — 어댑터는 측정 대상 시스템의 일부
- M7 전환 시 어댑터 지시문은 플러그인 훅으로 대체된다
- TECHNICAL §5.3.1에 반증 각주 병기 (원문은 보존)
