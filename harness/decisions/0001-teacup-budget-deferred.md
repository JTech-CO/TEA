# ADR-0001: 티컵 예산을 v1에서 제외하고 규율 축을 우선한다

- 상태: 채택 | 기록: 2026-08-13 (기술 백서 v0.3 §10.1~10.3 결정의 재구성 기록)

## 컨텍스트
이름 은유(차 한 잔)가 소비 상한 + 리필 확인 메커니즘을 시사하나, 임계값 초기치는 근거 없는 추측이다.

## 결정
v1은 규율 축(READ/WRITE/THINK)만 구현한다. 예산의 두 기능 중 차단은 제외하고, 계수는 사후 감사로 축소한다(M7 /tea-audit).

## 근거
- 벤치마크 오염 — 예산 포함 시 C군 악화의 원인 분리 불가
- 자기 모순 — 리필 확인은 턴 수를 늘려 채택 게이트 3번(턴 수 비증가)을 스스로 위반
- 실패 양상 — 규율 축은 완만한 열화, 예산은 급격한 실패(작업 중단·사용자 개입)

## 결과
누적 소비 분포가 v2 임계값의 실증 근거가 된다. 은유의 본체는 절제 철학으로 유지(§10.3).
