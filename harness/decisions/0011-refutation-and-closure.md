# ADR-0011: v1 반증 확정 — 프로젝트 종결, 후속 가설은 백서 부록 C로 승계

- 상태: 채택 | 기록: 2026-08-19 (M6 판정 + 사용자 결정)

## 컨텍스트
3군 288트라이얼 실측(sonnet-5·opus-5, n=48/셀, $151.70)에서 C−B 순기여가 두 모델 모두
양수(+18.8%/+17.2%)로 채택 게이트 5조건 AND를 미통과했다. 계측 의심 체크 전부 통과,
적대 검증 3에이전트 전부 판정 지지. 원인은 규칙 내용이 아니라 스킬 전달 라운드
(호출 콜의 기저 컨텍스트 25~34k 재과금 + 본문 주입 턴)이며, 단일 규칙 제거·주입형 전환
어느 쪽도 판정을 뒤집지 못한다(전환 확률 ≤1%).

## 결정
1. v1 가설("Ponytail이 남긴 계층 C 공백을 스킬 규율로 회수")을 **반증으로 확정**하고 종결한다.
2. 주입형 재측정(~$41)은 정보 가치 없음으로 기각한다.
3. 후속 연구 가설(장기·대형 세션 태스크셋 + 주입형 전달)을 **기술 백서 v0.4 부록 C**로
   사전 등록 형식(가설·설계·반증 조건 명시)으로 승계한다 — 사용자 결정.
4. 게이트·불변식·규칙은 무조정 상태로 보존한다. 반증은 phase 실패가 아니라 결과다
   (gates/DOD_GUIDE.md §4.4).

## 결과
- M7(플러그인 전환)·M8(크로스 에이전트)은 DoR(채택 전제) 미충족으로 영구 미착수.
- 승계 자산: bench/ 계측 하네스, 트리거 평가 방법론, 핸들 12종 조작적 정의, 규칙 원장.
- 일반화된 교훈 한 줄: **스킬 형태의 행동 규율은 전달 비용이 세션당 기저 컨텍스트
  1회분이므로, 회수 가능한 낭비가 그보다 작은 세션에서는 성립하지 않는다.**
