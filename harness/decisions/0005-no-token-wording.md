# ADR-0005: 규칙 문구에 "토큰"을 쓰지 않는다 — 행동만 기술

- 상태: 채택 | 기록: 2026-08-14 (기술 백서 §9.5, 설계 백서 §4.7 결정의 재구성 기록)

## 컨텍스트
목적 함수 동형성 — TEA와 목적(토큰=목적)이 같은 선행 도구는 caveman이며, 그쪽이 에이전트 세션에서 실패했다(+7%). "토큰을 줄여라"는 지시 자체가 측정 밖 축으로 비용을 전가하는 경향을 가질 수 있다.

## 결정
규칙 문구에 "토큰"·"짧게"·"줄여라"(영문 등가어 포함)를 금지한다(INV-5). 규칙은 행동 수준으로 기술하고, 토큰은 결과 지표로만 존재한다.

## 근거
Goodhart 방어를 코드 골프만이 아니라 TEA 자신에게 적용한다. 채택 게이트가 총 토큰 단독 판정을 금지하는 것(INV-7)과 같은 뿌리다.

## 결과
scripts/forbidden-terms.js가 집행한다. 검사 범위: SKILL.md 본문(frontmatter 제외) + tea/references/ + rules/catalog.json. description은 사용자 표현 매칭용이므로 "tokens" 언급 허용(DESIGN §3.2).
