# ADR-0004: LOC 배제 — 주지표는 총 토큰(추론 포함)과 턴 수

- 상태: 채택 | 기록: 2026-08-13 (기술 백서 §7.5·§8.1 결정의 재구성 기록)

## 컨텍스트
선행 벤치마크는 diff LOC를 주지표로 썼다. LOC를 지표로 삼는 순간 골프가 자동 발생한다(Goodhart의 법칙).

## 결정
LOC를 모든 지표에서 배제한다(INV-8). 주지표: 총 토큰 = input + output + **reasoning**(INV-10), 턴 수. 부지표: 재시도율·도구 호출 실패율·트리거율.

## 근거
reasoning을 빼면 사다리 추론 비용 위험(TECHNICAL §9.3)이 측정에서 사라진다. GPT-5.5 계열에서 사다리 숙고로 총 소비가 역전된 선행 보고가 있다.

## 결과
선행 하네스 재사용 시 스코어링만 교체한다(ADR-0006). M4 집계 스키마 게이트(INV-8·10)가 집행한다.
