# ADR-0003: SAY 축 제거 — 규율 축 3개 확정

- 상태: 채택 | 기록: 2026-08-14 (기술 백서 §6.4 결정의 재구성 기록)

## 컨텍스트
초안은 출력 표현(SAY)을 4번째 규율 축으로 두었다.

## 결정
READ/WRITE/THINK 3축으로 확정한다. 출력 표현 영역은 caveman에 위임하고, "코드 재진술 금지" 1건만 W5로 WRITE 축에 이관한다.

## 근거
- 정의역 중복 — caveman이 전용 점유 (단발 기준 출력 −65% 실측)
- **반증** — 같은 접근이 에이전트 세션에서 총 토큰을 +7% 증가시켰다(TECHNICAL §2.3). 정의역이 비어 있어도 채택할 근거가 없다
- 본문 경량화 — 축이 3개면 사다리도 4단계로 준다

## 결과
caveman 병용은 권고하지 않는다(총 토큰 지표 기준 순손실). W5는 스타일 규칙이 아니라 중복 삭제 규칙 — 경계는 DESIGN §4.6 (설계 근거·남은 선택지·부작용은 재진술 금지의 비대상).
