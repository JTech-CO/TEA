# ADR-0006: 선행 벤치마크 방법론 재사용 — 지표만 교체

- 상태: 채택 | 기록: 2026-08-14 (기술 백서 §8.3, 설계 백서 §6.1 결정의 재구성 기록)

## 컨텍스트
계측 하네스 자작은 비용이 크고, 자작하면 재현성 대조 기준도 없다.

## 결정
선행 사례의 방법론을 재사용한다 — 대상 tiangolo/full-stack-fastapi-template, 12개 feature 티켓, n=4, headless 실행, git diff 기반 채점. 스코어링만 LOC → 총 토큰·턴 수로 교체한다(ADR-0004).

## 근거
- 하네스 구축 비용 제거
- B군(Ponytail 단독) 수치를 선행 공개치와 대조 → 재현 실패 시 환경 문제를 TEA 문제와 분리할 수 있다(RUNBOOK #10)

## 결과
2군 가정 스크립트를 3군(A/B/C)으로 확장하는 부분만 신규 구현(INV-9). B군 재현 확인이 M5 DoD 1이다.
