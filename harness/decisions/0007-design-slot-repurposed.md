# ADR-0007: DESIGN 문서 슬롯을 스킬 산출물 명세로 용도 변경

- 상태: 채택 | 기록: 2026-08-14 (하네스 인스턴스화 시점 결정의 재구성 기록)

## 컨텍스트
하네스 팩의 DESIGN 슬롯은 통상 소프트웨어 설계(모듈·인터페이스·데이터 흐름)를 담는다. TEA의 산출물은 코드가 아니라 규칙 문서다.

## 결정
docs/DESIGN(설계 백서)은 산출물 명세를 담는다 — 파일 구조, 규칙 카탈로그와 ID 체계, description 문안, 평가셋 설계, 벤치마크 절차, 채택 게이트 운용.

## 결과
아키타입 3·4·7(데이터/API/UI)은 미적용으로 확정(gates/DOD_GUIDE.md §3). "규칙이 그럴듯하다"가 아니라 발화율·기준선 대비 개선이 게이트가 된다.
