# M6 — 규칙 정제·채택 판정 ★

> 근거: docs/TECHNICAL §8.4·8.5, docs/DESIGN §6.4·§7. 이 프로젝트의 중심 게이트 — 5조건 AND, 반증 허용(gates/DOD_GUIDE.md §4.4).

## 목적
규칙별 기여도로 음수 규칙을 제거하고, 채택 게이트 5조건을 판정한다.

## DoR (진입조건)
- [ ] M5 DoD 통과 (완전한 3군 데이터셋)

## 할 일
1. scripts/gate.js — 5조건 AND 판정기 (INV-7의 검증 수단)
2. 규칙별 기여도 — 핸들 12종 준수도 × 총 토큰 상관 분석
3. 음수 규칙 제거 → 원장·본문 동기 수정(한 커밋) → **재측정** (수정 후 수치로만 판정)
4. 적대적 티어 판정 — 불가침 5항목 C = B = 100%
5. 판정 기록 — 통과 시 채택, 미달 시 반증 보고(HARNESS §2.3 — 수치 맞추기는 레드라인)

## 롤백
규칙 제거는 원장·본문 커밋 단위 — 이전 커밋 복원. 판정 기록은 불변(폐기 시 표시만).

## 리스크
- C군 열세 → 계측 의심 → 규칙별 분리 → 반증 보고 순서 엄수(HARNESS §2.3, RUNBOOK #11). 규칙 조정으로 수치 맞추기는 레드라인
- 모델 간 역전 → 채택 불가, 역전 조건 문서화(RUNBOOK #14, DESIGN §7.3)
- 앵커 실패 증가 → W2 완화 후 재측정(RUNBOOK #12)
